# 时光机 AI 代运营系统 · 商家使用手册

> 本手册面向使用本系统的**本地商家**（餐饮、美业、零售、教培等）。
> 内容依据当前代码实现整理；凡属占位功能、尚不可用的，都在文中明确标注，避免照着操作踩空。

---

## 一、开始使用

### 1.1 注册

1. 打开站点首页，点「注册新账号」，或直接访问 `/sign-up`
2. 填写**邮箱**与**密码**，点「注册」
3. 注册成功后自动登录，并跳转到控制台 `/dashboard`

注册时系统会**自动为你创建一个团队**（默认名称为「你的邮箱's Team」），你是该团队的**所有者（owner）**。一个商家 = 一个团队，团队下可以管理多个门店。

### 1.2 登录

访问 `/sign-in`，输入注册时的邮箱与密码即可。

### 1.3 忘记密码

当前版本**没有自助找回密码**功能。请联系时光机代运营团队协助处理。

## 二、团队与成员

进入左侧菜单 **团队设置**。

| 功能 | 说明 |
|---|---|
| 团队订阅 | 查看当前套餐、开通或管理订阅 |
| 团队成员 | 查看成员列表与角色；通过「邀请团队成员」填写邮箱与角色发起邀请 |
| 操作日志 | 记录团队内的关键操作，便于追溯 |
| 安全设置 | 与账号安全相关的配置 |

### 角色说明

| 角色 | 权限范围 |
|---|---|
| 所有者 owner | 团队内最高权限，可管理订阅与全部成员 |
| 管理员 admin | 可管理门店、商品、AI 内容等业务功能 |
| 成员 member | 业务功能的日常使用 |

> 邀请链接由系统通过邮箱发出；被邀请人打开链接完成注册后，会自动加入你的团队并继承邀请时指定的角色。

## 三、门店管理

左侧菜单 **商家运营 → 门店管理**。

门店是你经营数据的二级隔离单元：**团队 → 门店 → 商品/订单**。

### 新增门店

填写门店名称、平台、域名（可选）、类目（可选）、币种等信息后保存。

### 接入电商平台（重要：当前可用性有限）

门店可以与外部平台打通，用于同步商品与订单。**但请注意当前的实现状态**：

| 平台 | 状态 |
|---|---|
| Shopify | **可用**（参考实现，需配置 `SHOPIFY_API_KEY` / `SHOPIFY_API_SECRET`） |
| 小程序 | **尚不可用**。适配器为占位实现，点击「接入小程序」会报错提示「平台「小程序」接入尚未实现」 |
| 淘宝 / 京东 / 拼多多 / 抖音 / Amazon | **尚不可用**，均为占位适配器，会返回明确报错 |

**小程序接入目前需要由时光机代运营团队协助开通**，暂不支持商家自助操作。

## 四、商品管理

### 4.1 单个添加

**商家运营 → 门店管理** 中选择门店，添加商品。可填写：标题、描述、类目、价格、SKU，以及自定义属性。

### 4.2 批量导入（推荐）

**商家运营 → 商品导入**，支持上传 CSV 文件或直接提交 JSON。

CSV 表头字段映射：

| 列名 | 说明 |
|---|---|
| `title` | 商品标题（必填，缺失该行会被跳过并记录错误） |
| `description` | 商品描述 |
| `category` | 类目 |
| `price` | 价格（非法值会被跳过并记录错误） |
| `sku` | 商品编码 |
| 其他列 | 自动作为自定义属性保存 |

说明：
- 支持带引号包裹、转义字符与 CRLF/LF 换行
- 导入前会**预检配额**，超出套餐上限会返回 402 并提示升级
- 分批写入（每批 200 条），大批量导入不会一次性卡住

## 五、四大 AI 场景

左侧菜单 **商家运营** 下。这四个场景是本系统的核心能力，按套餐档位解锁。

### 5.1 AI 文案创作

输入门店/项目信息，生成多版本营销文案。典型用途：门店介绍、项目卖点、小程序商品详情、朋友圈文案。

### 5.2 AI 营销策划

生成开业、节日活动、社群裂变等活动的方案与配套话术，以及短视频脚本。

### 5.3 AI 智能客服

针对预约、营业时间咨询、售前售后等问题生成专业回复，**支持多轮对话**（会携带最近若干轮上下文）。

配合 **客服知识库** 使用效果更好：把常见问答录入知识库后，AI 会检索命中内容并注入到回复中。

### 5.4 经营数据洞察

解读客流、销售、会员等经营数据，输出结论与优化建议。

### 套餐解锁关系

| 场景 | Free | Pro | Business | Enterprise |
|---|---|---|---|---|
| AI 文案创作 | ✓ | ✓ | ✓ | ✓ |
| AI 营销策划 | ✗ | ✓ | ✓ | ✓ |
| AI 智能客服 | ✗ | ✓ | ✓ | ✓ |
| 经营数据洞察 | ✗ | ✓ | ✓ | ✓ |

未解锁的场景会显示「升级解锁」引导。**实际可用的档位与价格请以 `/pricing` 页面为准**。

## 六、客服知识库

**商家运营 → 客服知识库**。

维护 FAQ 问答对（问题、答案、分类、标签），可逐条启用/停用。AI 智能客服在回复时会检索知识库，命中的内容会作为上下文注入，从而给出更贴合你门店的答案。

## 七、套餐、用量与计费

### 7.1 套餐档位

进入 **团队设置 → 团队订阅** 查看当前套餐与订阅状态；点「管理订阅」可跳转 Stripe 完成开通、变更或取消。

各档位的**价格、Token 配额、项目数、成员数、每日 API 次数、门店数上限**均以 `/pricing` 页面与订阅页展示为准。档位大致为 Free / Pro / Business / Enterprise 四档，能力与额度逐级提升。

### 7.2 用量统计

**AI 助手 → 用量统计**，查看 Token 消耗与 API 调用情况。

### 7.3 超额计费

订阅套餐包含每月免费 Token 配额，**超出部分按档位单价计费**，账单明细会记录在计费台账中。

> 注：超额计费需要运维侧配置 `STRIPE_OVERAGE_METER_NAME` 后才能生效。若你的账号下未显示超额明细，说明该配置尚未启用。

### 7.4 配额超限会怎样

调用 AI 或创建项目/邀请成员前会做配额校验，超限时返回 **HTTP 402（Payment Required）**，界面会提示你升级套餐。

## 八、AI 助手与开放接口

### 8.1 AI 项目

**AI 助手 → AI 项目**，用于配置独立的 AI 项目（可指定系统提示词与模型）。适用于希望针对特定业务单独调优的场景。

### 8.2 API Keys

**AI 助手 → API Keys**。

- 生成的密钥格式为 `sk-saas_xxx`
- **明文只在创建时显示一次**，请立即妥善保存；系统仅存储其哈希值，之后无法再次查看
- 可设置有效期，过期的密钥自动失效

### 8.3 开放接口

持有 API Key 后，可调用对外接口 `POST /api/v1/chat`（接口风格兼容 OpenAI），用于把 AI 能力接入你自己的系统。

接口受**按租户与密钥维度的速率限制**保护。

## 九、常见问题

**Q：注册后没有看到我的团队？**
正常情况下注册会自动创建团队。若异常，请刷新页面或联系代运营团队。注意「团队设置 → 团队成员」中应能看到你自己，角色为「所有者」。

**Q：为什么某个 AI 场景点不开？**
该场景未包含在你当前套餐中。Free 档仅含「AI 文案创作」，其余三个场景需要 Pro 及以上。

**Q：提示 402 是什么意思？**
配额超限。可能是当月 Token 用尽、当日 API 次数超限，或门店/商品数量达到上限。

**Q：导入商品时部分行没进来？**
标题缺失或价格非法的行会被跳过并记录错误，请检查 CSV 对应列。另外请确认未超出套餐的商品数量上限。

**Q：点击「接入小程序」报错？**
该功能尚未实现（占位适配器）。小程序接入需由时光机代运营团队协助开通。

**Q：API Key 找不到了？**
出于安全设计，明文只在创建时显示一次，不可找回。请删除旧密钥并新建。

## 十、给运维/管理员的提示

手册中涉及**套餐价格与配额数值**的部分，请以系统实际配置为准——这些值存于数据库的 `plans` 表，可在运行时调整，不必改动代码。

若商家反馈「登录后看不到团队」「注册失败」等异常，通常与租户隔离策略有关（系统启用了数据库级行级安全），请把**发生时间与操作步骤**提供给运维侧，以便从服务端日志定位。
